工具优先级：
· 文本处理：awk/sed/grep → perl/ruby
· 媒体处理：ffmpeg/ffprobe → imagemagick
· 网络请求：curl → wget/httpie
· 加密随机：openssl → /dev/urandom
· 容器操作：docker → podman
· JSON处理：jq → python -m json.tool
· 压缩归档：tar/gzip → zip/7z
· 进程管理：ps/pgrep/kill → htop/lsof

默认约定：
· Shell：zsh（兼容bash）
· 路径：相对优先，~展开为$HOME
· 引号：变量用"$var"，字面量用'string'
· 错误处理：关键链加|| exit 1或set -e提示
· 空格安全：所有变量默认双引号防文件名爆炸
